# 小红书笔记存档 XHS Note Archiver

一个轻量级的油猴脚本（Tampermonkey Script），用于把当前小红书笔记的图片、视频、正文以及已加载的评论存到指定文件夹，每篇笔记自动生成一个独立子目录。

## 设计前提

**不主动发起任何小红书站内 API 请求。**
- 正文、作者、标签、互动数据、评论 → 纯内存读取页面已有的 `__INITIAL_STATE__` 数据与 Meta 标签，零 API 请求。
- 图片与视频 → 只请求静态 CDN 资源（如 `xhscdn.com`、`rednotecdn.com`）。
- **优势**：完美规避站内风控（不会触发 `300013` 等限流错误）。

---

## 功能特点

- **多媒体完整存档**：
  - **图文笔记**：自动下载所有高清图片，支持 WebP 转 PNG（选填）。
  - **视频笔记**：支持自动解析无水印原片 (`originVideoKey`) 与高画质串流（`EF4` 等格式），带实时下载进度显示。
- **正文与评论导出**：支持将标题、作者、IP 属性、互动数据、完整正文以及页面已加载的评论（支持点赞门槛筛选）导出为排版清晰的 `.txt` 档案。
- **现代化体验**：原生整合 File System Access API（文件夹授权持久化），每篇笔记自动建立专属子目录，并支持“同名文件已存在自动跳过”。

- 评论区仅能获取当前页面已加载（已滚动浏览到）的部分评论。

---

## 使用说明

1. 安装油猴插件（Tampermonkey）。
2. 安装本脚本。
3. 打开任意小红书笔记页面，右下角会出现「📁 点此选择保存位置」与「⬇ 下载笔记」按钮。
4. 首次使用点击文件夹按钮授权存储文件夹，随后即可一键畅快存档！
