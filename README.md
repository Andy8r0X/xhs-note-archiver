# 小红书笔记存档 · XHS Note Archiver

一个油猴脚本。在小红书网页版的笔记页加一个按钮，把这篇笔记的**图片**和**正文**打包存到你指定的本地文件夹，每篇笔记一个子目录。

给自己收藏攻略用的，省得一张张右键另存。

```
小红书收藏/
├─ 保姆级零基础找Agent开发实习怎么优化简历项目_0312e2/
│  ├─ 保姆级零基础找Agent开发实习怎么优化简历项目.txt
│  ├─ 01.webp
│  ├─ 02.webp
│  └─ 03.webp
└─ 咩_01ee52/
   ├─ 咩.txt
   └─ 01.webp
```

## 设计原则：零 API 请求

这是这个脚本和其他同类工具最主要的区别。

- **正文、作者、标签、评论** —— 读页面加载时就已经存在的 `window.__INITIAL_STATE__`，纯内存操作
- **图片** —— 只请求 `xhscdn.com`（静态 CDN，与站内 API 是两套系统）

脚本**不调用任何 `xiaohongshu.com` 的接口**，不做分页，不模拟滚动，不碰签名。所以不会触发 `300013 安全限制 / 访问频繁`。

代价是评论只能拿到页面当前已加载的那部分。想多要，自己往下滚几屏、点开想留的回复，再点下载——按钮上会实时显示当前有多少条。

> 早期版本试过自动滚动翻页来抓全部评论，实测很容易触发限流，且恢复要等数小时。这个功能已经彻底移除，不建议再加回来。

## 安装

1. 装 [Tampermonkey](https://www.tampermonkey.net/)（Chrome / Edge / Firefox 均可）
2. 点这里安装脚本：[xhs-note-archiver.user.js](https://raw.githubusercontent.com/firmamento73/xhs-note-archiver/main/xhs-note-archiver.user.js)
3. 打开 <https://www.xiaohongshu.com> 的任意笔记页，刷新一下

## 使用

页面右下角出现三个按钮：

| 按钮 | 作用 |
| --- | --- |
| `💬 不含评论` | 点击切换是否把评论写进 txt，状态会记住。开启后显示当前已加载条数 |
| `📁 点此选择保存位置` | 选一次本地文件夹，之后自动复用 |
| `⬇ 下载笔记` | 开始打包 |

第一次点下载会弹系统文件夹选择框。**每个浏览器会话首次写入时**，Chrome 会问一次「让此站点编辑文件？」——这是 File System Access API 的硬性要求，权限不跨会话保留，但选过的目录本身会记住，不用重选。

生成的 txt 大致长这样：

```
果然计算机找实习最快的方式就是翻评论区

作者：wuu  (5f3a8b...)
发布：2026-01-02 14:33  IP 湖南
互动：赞 497 · 藏 471 · 评 9
图片：4 张
链接：https://www.xiaohongshu.com/explore/...
存档：2026-08-07 10:22

──────────── 正文 ────────────

家人们谁懂啊！...

#前端开发 #实习 #计算机
```

## 配置

脚本顶部的 `CONFIG` 对象：

| 项 | 默认 | 说明 |
| --- | --- | --- |
| `saveText` | `true` | 生成正文 txt |
| `saveJson` | `false` | 额外存一份 `note.json` 原始数据，方便以后改格式或做本地检索 |
| `convertToPng` | `false` | 把 webp 转成 png。体积涨 2~4 倍，一般不需要 |
| `txtCRLF` | `true` | 用 `\r\n` 换行，记事本友好 |
| `skipExisting` | `true` | 同名图片已存在就跳过，重复点同一篇不会白下 |
| `imageDelay` | `400` | 图片之间的间隔毫秒数 |
| `comments.minLikes` | `0` | 只保留点赞数 ≥ 此值的一级评论 |
| `comments.maxCount` | `0` | 按点赞取前 N 条，`0` 为不限。取完会还原成原始楼层顺序 |
| `comments.subMinLikes` | `0` | 楼中楼的点赞门槛 |

## 兼容性

- **File System Access API**（任选目录）需要 Chrome / Edge 86+。Firefox 至今未实现。
- Firefox 下自动降级为 `GM_download`，文件落在 `浏览器下载目录/xiaohongshu/{标题}/`。此时需要在 Tampermonkey 设置里把「下载模式」设为**浏览器 API**，否则子目录会被忽略。

## 已知限制

- 只处理图文笔记。视频笔记会存下正文和封面，不下视频。
- 评论只有页面已加载的部分，且楼中楼可能自带二级分页，未做处理。
- 图片默认是 webp。URL 里 `!` 后面是 CDN 的处理指令，脚本会先试去掉后缀取原图，失败则回落到原始地址——小红书调整 CDN 规则时这套候选链可能需要更新。
- 依赖 `__INITIAL_STATE__` 的结构。小红书改版时可能需要调整 `readState()`。出问题先看控制台。

## 排查

**按钮没出现** —— 装脚本前就打开的页面需要刷新。仍然没有的话，可能被小红书自己的悬浮控件盖住了，改脚本里 `bottom: '110px'` 试试。

**图片全部失败** —— 控制台会打印每张图试过的所有候选地址和失败原因。如果全是 `HTTP 403`，说明 CDN 开始校验签名参数，把 `strip()` 改成只去 `!` 后缀、保留 `?` 后面的 query。

**「没读到笔记数据」** —— 控制台执行 `Object.keys(__INITIAL_STATE__.note.noteDetailMap)` 看看结构是否变了。
